# DEEP SEA 작업 노트

> 작성: 2026-09-29
> 결과물: `deepsea/index.html` (빌드 결과. 직접 고치지 않는다)
> 원본: `deepsea/index.src.html` (HTML, CSS) + `deepsea/src/*.js` (구역별 스크립트) → `node deepsea/build.mjs`
> 썸네일: `assets/thumb/deepsea.webp` (960x540, 1600x900 박명 구역 해파리 장면 u 2.47 을 줄임)

## 방향

햇빛이 일렁이는 수면 바로 아래에서 시작해 산호초, 박명층, 자정층, 심연까지 내려갔다가 거품을 타고 다시 수면으로 올라온다.
색은 밝은 청록에서 짙은 남색, 검정으로 내려가고 깊은 곳에서는 생물 발광 네온(청록, 마젠타, 라임, 바이올렛)만 남는다. 크림, 아이보리, 회백색은 쓰지 않았다.
수심계, 숫자, 장면 카운터는 화면에 없다. 서체는 제목 DEEP SEA 에 Unbounded 900(캔버스에 그려 셰이더로 굴절), 한글 구역 단어에 Pretendard Variable 800.
화면 문구는 구역 단어 넷(빛이 닿는 곳, 푸른 어스름, 한밤의 바다, 심연)과 끝의 "다시 빛으로", 버튼 "목록으로" 뿐이다.

## 구역과 길이

`--len` 에 `:root --scroll-stretch`(1)를 곱한다. reduced-motion 은 정지 화면만 보여 주므로 0.4 로 줄인다.

| 구역 | --len | 핵심 기법 |
|---|---|---|
| 수면 | 1000vh | 풀스크린 셰이더. 시선 광선을 물결 높이장에서 굴절(스넬의 창), 임계각 밖은 전반사, 화면 공간 빛내림, 굴절되는 DEEP SEA 제목, 수면을 가로지르는 만타가오리 실루엣(SDF) |
| 산호초 | 1300vh | Voronoi 가장자리 두 겹으로 만든 움직이는 커스틱, 다시마 흔들림, 해면과 부채산호, 물고기 떼 보이드 300마리(포인터로 흩어짐), 산호초 끝 절벽 |
| 박명층 | 1200vh | 푸른색이 빠지며 바다눈, 해파리 8마리(선반 회전체 종, 수축 박동, 프레넬 발광, 박동보다 늦게 따라오는 촉수 선) |
| 자정층 | 1300vh | 깜빡이는 관해파리 사슬, 발광기관, 속도에 반응하는 플랑크톤, 앞서 가는 초롱아귀 미끼, 포인터 손전등(SpotLight)으로만 보이는 생물, 끝에 초롱아귀 등장 |
| 심연 | 1200vh | 열수 분출구, 광맥 발광, 연기 입자, 최종 패스 열 아지랑이, 앞을 지나가는 거대한 향유고래 실루엣, 마지막 빗해파리 한 마리 |
| 다시 수면 | 1000vh | 인스턴스 거품 700개가 올라가고 배경은 수면 셰이더가 어둠에서 밝아진다, 자석 버튼(`../`) |
| 합계 | 7000vh | 900px 화면 63,000px, 720px 화면 50,400px, 375x812 56,840px, reduced(900px) 25,200px |

## 기법과 수치 (전부 `src/00-core.js` 의 `CONFIG`)

**스크롤 → 잠수 좌표 u.** Lenis(lerp 0.08)만 쓰고 ScrollTrigger 는 쓰지 않았다. 구역 섹션 6개의 offsetTop 과 높이로 u = 구역 번호 + 구역 안 진행률(0~6)을 계산한다. 마지막 구역은 높이에서 한 화면을 빼서 문서 끝에서 정확히 6이 된다.

**구역 전환.** 렌더러 하나, 캔버스 하나. 구역마다 scene 과 camera 가 따로 있고 `ZonePass`(EffectComposer 첫 패스)가 지금 구역을 HalfFloat 타깃에 그린다. 경계 앞뒤 u 0.045 안에서는 두 구역을 모두 그리고 fbm 임계값으로 섞는다. 임계값에 화면 세로 좌표를 0.28 섞어서 다음 구역이 화면 아래에서 물이 차오르듯 올라온다. 경계에는 UV 흔들림과 옅은 청록 테두리가 붙는다. 보이지 않는 구역은 그리지 않는다.

**후처리.** ZonePass → UnrealBloom(0.72, 0.6, 임계 0.78) → 최종 패스(열 아지랑이, 속도 색수차, 손전등 산란광, 비네트, 그레인) → OutputPass(ACES, 노출 1.05). DPR 1.5 제한. MSAA 는 데스크톱 4, 모바일 0.

**속도.** `|lenis.velocity| × 0.022` 를 1.6 까지 자르고 0.07 로 따라간다. 이 값 하나가 거품과 줄무늬 늘어짐(최대 22배), 색수차(0.0018 + 속도 × 0.0035), 자정층 플랑크톤 섬광, 물고기 최고 속도, 빛내림 세기를 움직인다. 줄무늬 층은 모든 구역 위에 따로 그리는 화면 공간 쿼드 520개(모바일 300)이고 구역마다 색, 세기, 거품 모양 비율이 다르다(`CONFIG.drift.looks`).

**수면 셰이더.** 수심 2.5 → 20, 시선 각도 0.78 → 0.36 라디안. 굴절률 1.33. 해 방향은 수중에서 보이는 겉보기 방향으로 화면에 투영해 빛내림의 중심으로 쓴다. 해 하이라이트는 `pow` 대신 곱셈 16번(블룸 NaN 방지, MUSEUM 교훈). 제목은 처음에 흰색으로 했더니 밝은 스넬의 창에 묻혀 안 보였다. 짙은 남색 글자 + 옅은 그림자로 바꾸자 빛 속의 실루엣으로 읽혔다. 만타는 u 0.36~0.98 에 화면 오른쪽에서 왼쪽으로 지나가고 날개 끝이 날갯짓에 맞춰 휜다.

**커스틱.** 격자 셀 안에서 움직이는 점으로 구한 F2 - F1(Voronoi 가장자리)을 두 배율로 겹치고 입력 좌표를 값 노이즈로 0.9 비튼다. 곧은 다각형 그물이 물결 무늬가 된다. 위를 향한 면에만 곱하고 수심 -6 아래에서는 꺼진다. 이 함수 하나를 해저, 바위, 해면, 수면 아랫면 반짝임이 같이 쓴다.

**물고기 떼.** CPU 보이드. 이웃 7마리(반경 3.2)로 분리 0.9, 정렬 1.1, 응집 0.7. 집 위치는 카메라 앞 14, 해저 위 2.5 이상이고 상자(8, 3.5, 6) 밖으로 나가면 제곱으로 당긴다. 포인터 광선에서 4.2 안이면 광선에서 멀어지는 힘 26 과 최고 속도 11. 꼬리 흔들림은 정점 셰이더에서 인스턴스별 위상과 박자로. 등은 파랑 또는 마젠타, 배는 밝은 은청색, 옆줄과 꼬리는 노랑.

**해파리.** 종은 LatheGeometry(56분할), 박동 곡선은 0~0.18 에 빠르게 수축하고 0.75 까지 천천히 펴진다. 가장자리일수록 많이 움직인다. 촉수 22개(그중 넷은 굵은 구완)를 LineSegments 26마디로 만들고 박동 위상을 마디마다 0.6 늦춘다. 전부 가산 합성이라 겹칠수록 밝다.

**초롱아귀와 손전등.** 자정층은 MeshStandard 생물과 빛만 있다. 손전등은 카메라 위치의 SpotLight(200, 각 0.34, 감쇠 1.6), 방향은 포인터 광선이다. 포인터가 1.8초 움직이지 않거나 터치 기기면 스스로 천천히 훑는다. 바다눈은 손전등 원뿔 안에서만 밝아진다. 초롱아귀 몸은 미끼가 앞장서는 동안 22 뒤 어둠(안개)에 있다가 u 3.62~3.76 에 미끼 뒤로 다가오고, 그때 손전등이 얼굴로 끌려간다. 가까워지면 손전등 세기를 0.22 배로 낮춘다(안 그러면 얼굴이 하얗게 날아감). 턱은 늘인 타원체의 아래쪽 반을 0.22 라디안 벌린 것이고 아래 이빨이 길다. 정면 대칭으로 두면 웃는 얼굴 이모티콘처럼 보여서 0.4 라디안 돌려 3/4 각도로 보인다.

**심연.** 분출구 5곳, 곳마다 굴뚝 셋. 바위 셰이더가 분출구 거리로 빛을 받고, 가까운 곳의 Voronoi 광맥이 맥동하며 빛난다. 연기는 입자 700개(모바일 420)가 16 높이까지 오르며 넓어지고 해류에 휜다. 최종 패스는 분출구 입구를 화면에 투영한 기둥 영역에서 UV 를 노이즈로 흔든다(열 아지랑이). 향유고래는 회전체 몸통 + 꼬리지느러미, 거의 검정에 옅은 코발트 테두리로 u 4.3~4.74 에 오른쪽에서 왼쪽으로 지나간다. 끝의 빗해파리는 8줄 빗판에 무지개 빛이 흐르고 나머지 빛은 0.2 까지 어두워진다.

**다시 수면.** 거품은 InstancedBufferGeometry 구 700개, 프레넬 테두리 + 하이라이트. 배경은 수면 셰이더를 수심 60 → 2.2 로 올리며 어둠(uDark 1 → 0)에서 밝힌다. 처음과 같은 셰이더라 내려간 곳으로 돌아온 느낌이 난다.

**reduced-motion.** Lenis 끔, 구역마다 정지 시점 하나(`STILL`)와 고정 시각 7.3 으로 그리고 스크롤이 있을 때만 다시 그린다. 경계는 섞지 않고 컷으로 넘긴다. 물고기는 무리 모양으로 고정, 줄무늬 속도 0, 구역 단어와 버튼은 켜짐, 꺼짐만 한다.

**일시 정지.** 탭이 숨으면 그리지 않는다. 캔버스가 fixed 전체 화면이라 화면 밖으로 나가는 경우는 없고, 대신 지금 보이는 구역(경계에서는 둘)만 그린다.

## 함정 (전부 실제로 걸림)

- **밝은 수면 위 흰 제목은 안 보인다.** 스넬의 창과 블룸이 흰 글자를 삼켰다. 남색 실루엣으로 바꿨다.
- **돔 색과 안개 색이 다르면 먼 지형 경계가 도형처럼 보인다.** 심연에서 해구 벽 사이 틈이 파란 종 모양으로 떠 보였다. `?debug` 로 장면 자식을 하나씩 숨겨 원인이 바닥 메시와 돔의 색 차이임을 찾았다. 돔 색을 안개 색에 맞추고 벽을 시야 밖(|x| 60)으로 밀었다. 산호초 절벽 아래도 같은 이유로 어두운 띠가 생겨서 깊은 면은 돔 아래색으로 섞는다.
- **초롱아귀 미끼 후광 스프라이트가 얼굴을 덮는다.** 가산 스프라이트는 앞에 있으면 몸 위에 그대로 더해져 얼굴이 청록 안개가 된다. 큰 후광을 없애고 작은 글로만 남겼다.
- **부채산호 격자가 크면 철망처럼 보인다.** 셀 밀도 13x15, 선 두께 임계 0.06, 절벽 띠의 부채는 수를 줄이고 작게.
- **초롱아귀 머리 안쪽 입 패치.** 평면 원판은 타원체 곡면에서 떠 보인다. 머리보다 1.2% 큰 타원체의 일부(phi, theta 범위)로 입을 만들어 곡면에 붙였다.
- 빠르게 스크롤하는 도중 Playwright 스크린샷은 fixed 캔버스와 문서가 어긋나 전체가 검거나 위에 검은 띠가 찍힌다. 인수인계서 6절의 합성 문제와 같다. 멈춘 뒤 찍으면 정상이다.

## 재료

이미지 생성 없음. 수면, 산호초, 물고기, 해파리, 초롱아귀, 분출구, 고래, 빗해파리, 거품 전부 셰이더와 Three.js 기본 도형으로 절차 생성했다. 그래서 `build.mjs` 는 텍스처 인라인 없이 `src/*.js` 만 이어 붙인다(HTML 약 106KB). `file://` 에서도 WebGL 캔버스 오염이 없다.

## 검증 (2026-09-29)

Playwright 1.63, 로컬 `python -m http.server 4231 --bind 127.0.0.1`.
1440x900, 375x812(모바일, 터치, DPR 2), reduced-motion(1440x900), file:// 네 조건에서 콘솔 오류 0, 경고 0, 실패 요청 0, 4xx 0, 가로 넘침 없음(조건마다 11지점).
1280x720 에서 문서 전체를 휠로 300px 씩 내리며 균등 40지점을 1.5초씩 기다려 찍었다. 한 색 비율 95% 넘는 거의 빈 화면 0장(가장 높은 단색 비율 0.68, 4비트 색 구간 기준).
속도 반응(빠른 휠에서 줄무늬 늘어짐), 손전등(포인터 오른쪽 위), 물고기 흩어짐(포인터 통과)을 따로 찍어 확인했다.
스크린샷은 세션 scratchpad `lab-deepsea/`. 검사 중에만 쓰는 훅: 주소에 `?debug` 를 붙이면 `window.__deepsea` 에 THREE, gfx, zones, diveU, lenis 가 걸린다.
