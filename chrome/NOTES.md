# CHROME 작업 노트

> 작성: 2026-09-28
> 결과물: `chrome/index.html` (빌드 결과. 직접 고치지 않는다)
> 원본: `chrome/index.src.html` (HTML, CSS) + `chrome/src/*.js` (장면별 스크립트) → `node chrome/build.mjs`

## 방향

AFTER DARK 의 검정 바탕 네온과 반대로 간 Y2K 레트로 퓨처리즘이다. 밝은 하늘색과 페리윙클 하늘, 은색 크롬, 무지개 홀로그램.
생성한 하늘 이미지 한 장이 CSS 배경이면서 크롬 반사 환경이기도 해서 모든 오브제가 같은 하늘을 비춘다.
서체는 디스플레이 Unbounded(구글 폰트, 900), 한글 Pretendard Variable.

## 장면

`--len` 에 `:root --scroll-stretch`(기본 1.5)를 곱한다. reduced-motion 이면 포스터 상태라 배율을 0.4 로 줄인다.

| 비눗방울 POP | 1200vh | 1800vh | 인스턴스 비눗방울 56개(모바일 34), 박막 간섭색 셰이더, 노이즈로 찢어지며 터짐 |

## 기법과 수치 (전부 `src/00-core.js` 의 `CONFIG`)

**렌더러 하나, 투명 캔버스.** AFTER DARK V 처럼 fixed 캔버스 하나를 장면별 뷰포트 + 시저로 나눠 쓴다. 차이는 `alpha: true` 에 clear 알파 0 이라는 점이다. 캔버스는 `z-index: 2`, `pointer-events: none` 이고 각 pin(z 1)의 CSS 하늘과 글자가 캔버스 아래에 깔린다. 그래서 비눗방울과 크롬이 글자 앞을 지나간다. 버튼은 캔버스가 포인터를 통과시키므로 그대로 눌린다. 비행 장면만 WebGL 이 하늘을 불투명하게 그리므로 그 pin 은 `z-index: 3` 으로 캔버스 위에 둔다.

**하늘 환경맵.** RoomEnvironment 에서 방 벽과 상자(MeshStandardMaterial)를 숨기고 면광원만 0.22 배로 남긴다. 반지름 45 의 구 안쪽에 생성한 하늘을 등장방형으로 입히고, 지평선 아래는 하늘을 위아래로 뒤집어 (0.42, 0.52, 0.95) 배로 어둡게 한 색에 #2a45a8 을 섞는다. 처음엔 아래쪽을 단색 남색으로 칠했더니 크롬 아래 절반이 잉크 덩어리처럼 보였다. 뒤집은 하늘을 쓰면 아래에도 구름 결이 남는다. PMREM blur 0.015.

**액체 크롬.** `MeshPhysicalMaterial`(metalness 1, roughness 0.05)에 `onBeforeCompile` 로 끼운다. 정규화한 위치에서 변위를 구하고 접선 두 방향으로 0.012 떨어진 점을 한 번씩 더 변위해 외적으로 법선을 다시 만든다. 이게 없으면 반사가 원래 구 그대로라 액체처럼 안 보인다. 스크롤: 진폭 0.07→0.34, 주파수 1.1→2.3(0.08~0.34), y 축 비틀림 최대 2.4(0.36~0.62), 가라앉음(0.66~0.9), 퇴장(0.95~1). 포인터 방향으로 `pow(dot, 5) * 0.55` 만큼 부푼다.

**비눗방울.** 한 방울이 장면의 0.22~0.42 동안 화면 아래 0.85 에서 위 0.85 까지 올라가고, 생의 0.4~0.78 지점에서 터진 뒤 다음 생에 다른 x 로 다시 태어난다(해시가 방울 번호와 생 번호를 받아 매번 같은 배치). 처음엔 방울마다 한 번만 터지게 했더니 후반이 텅 비었다. 셰이더는 프레넬 2.4, 박막색 `0.5 + 0.5 cos(2π(t + (0, .33, .67)))`, 하늘 반사, 스펙큘러 두 점. 터짐은 값 노이즈가 문턱보다 작으면 discard 하고 찢어진 가장자리를 무지개로 빛낸다. 포인터가 닿으면 터지고 2.6초 뒤 다시 자란다.

**홀로 카드.** 평면 하나에 SDF 로 모서리를 깎는다(`fwidth` 안티에일리어싱). 포일 텍스처 좌표를 `tilt + normal.xy * 0.7` 로 밀고 박막색을 곱해 그림의 밝은 부분에 더 얹는다. 반짝이는 격자 칸마다 둥근 점 + 네 갈래 빛이고 기울기 위상으로 깜빡인다. 처음엔 사각 픽셀이 찍혀 지저분했다. 뒷면은 포일 + 동심원. 순서: 입장(0~0.07) → 부채(0.07~0.3) → 카드마다 앞으로 나와 한 바퀴 뒤집힘(0.3~0.5, 0.5~0.7, 0.7~0.9) → 위로 퇴장. 자이로는 AFTER DARK V 방식 그대로(iOS 는 `requestPermission` 이 있을 때만 "기울기 켜기" 버튼).

**녹는 글자.** helvetiker bold 를 jsdelivr 에서 받아(JSON 이라 file:// 에서도 된다) 크기 1, 두께 0.42, 베벨 0.14/0.07 로 둥글게 부풀린다. 앞면 삼각형이 커서 변위가 계단지므로 TessellateModifier(0.045, 10)로 쪼갠다. 흘러내림 `melt * h² * (0.2 + 1.25 * column(x))`, column 은 사인 곱의 세제곱이다. JS 에도 같은 함수를 두어 방울이 가장 긴 줄기 끝에서 떨어진다. 녹음은 0.1~0.55 에 최대 0.8, 0.8~0.95 에 복구. 스크롤 속도 스프링(이득 0.018, 강성 0.08, 감쇠 0.82)이 흔들림과 녹음을 더한다. 줄기 계수를 1.9 로 두었을 때는 줄기가 화면 밖으로 빠져 방울이 안 보였다.

**하늘 비행.** 경로 `x = sin(5t) * 3.2, y = sin(3.2t + 1) * 1.4, z = -320t`. 도형 5종(토러스, 가는 링, 별 압출, 구, 캡슐) 종류마다 34개(모바일 20), 경로에서 2.6~15 떨어진 곳에 둔다. 36 마다 큰 링을 경로 방향으로 세워 통과하게 한다. 구름은 캔버스로 그린 퍼프 스프라이트 46개(모바일 28), 카메라와 거리 30→6 에서 사라진다(가까운 구름이 화면을 하얗게 덮던 문제). 블룸 0.5/0.6/임계 0.92, 합성 타깃 HalfFloat + samples 4(모바일 0). 스크롤 속도로 FOV 가 최대 16도 벌어진다.

**성능.** DPR 1.5 제한, 보이는 장면만 그린다(ScrollTrigger onToggle), reduced-motion 은 스크롤이 있을 때만 다시 그린다.

## 함정

- `background-clip: text` 를 부모에 주면 transform 걸린 자식 span 글자에는 칠해지지 않는다. 글자를 쪼갠 제목은 `.ch` 마다 크롬 그라데이션을 준다.
- Unbounded 는 글자 폭이 매우 넓다. `CHROME` 이 1440px 을 넘쳐 잘렸다 → `--hero-size: min(15vw, 15rem)`.
- 알약 모양 스크롤 신호가 숫자 0 처럼 보였다. 세로 선으로 바꿨다.
- `will-change: transform` 이 걸린 버튼은 쌓임 맥락이 생겨 `::before { z-index: -1 }` 이 배경 위에 그려진다. 무지개 테두리는 `padding-box` / `border-box` 배경 두 겹으로 만든다.
- 이미지 생성 프록시가 1536x1024 를 요청해도 오브제 이미지는 1254 정사각, 하늘은 1774x887 로 왔다. 카드 셰이더가 cover 로 잘라 쓰니 상관없다.
- 소스를 여러 파일로 나눴지만 file:// 는 모듈 파일을 못 불러온다. `build.mjs` 가 `src/*.js` 를 이름순으로 이어 붙여 인라인 모듈 하나로 만든다. 파일 이름의 숫자가 순서다.
