# POP-UP 작업 노트

> 작성: 2026-09-28
> 결과물: `popup/index.html` (빌드 결과. 직접 고치지 않는다)
> 원본: `popup/index.src.html` (HTML, CSS) + `popup/src/*.js` (파일 이름 순서대로 이어 붙임) → `node popup/build.mjs`

## 방향

3D 종이 팝업북. 스크롤하면 책이 열리고 장이 넘어가며, 펼침면마다 채도 높은 색지 구조물이 접혀 올라온다.
색지는 토마토, 코발트, 에메랄드, 해바라기, 핫핑크, 딥틸. 책의 바탕 페이지는 순백 또는 원색(도시는 해바라기, 우주는 코발트)이다.
크림, 아이보리, 베이지, 크라프트 갈색은 쓰지 않았다. 책 주변은 펼침면마다 다른 깊은 단색 테이블에 부드러운 원형 조명.
화면 문구는 3D 종이 글자(POP-UP, FOREST, CITY, OCEAN, SPACE), "스크롤", "목록으로", iOS 의 "기울기 켜기" 뿐이다. 숫자, 카운터, 대문자 눈썹 라벨 없음.

## 기법과 수치 (전부 `src/00-core.js` 의 `CONFIG` 와 각 장면 파일 상단 상수)

**타임라인 하나.** ScrollTrigger 없이 섹션 `offsetTop` 으로 `t = 펼침면 번호 + 섹션 안 진행도` 하나를 만든다(마지막 섹션은 최대 스크롤까지). 모든 연출이 `t` 의 순수 함수라 되감아도 그대로 돌아간다. 시간 기반 움직임(날갯짓, 파도 흔들림, 별 흔들림, 불꽃)만 따로 시계를 쓴다.

**책.** 잎 5장(0 앞표지, 1~3 페이지, 4 뒤표지). 잎 k 는 척추(x = 0)를 축으로 `t = k + 1 - 0.22 ~ k + 1 + 0.08` 동안 0 → π 돈다. 두께: 보드 0.055, 페이지 0.022, 잎 사이 여유 0.05. 오른쪽 더미 높이는 자기 아래 잎들의 (두께 + 여유) 합, 왼쪽은 이미 넘어간 잎들의 합이다. 앞면(recto) 앵커는 잎 윗면, 뒷면(verso) 앵커는 잎 아랫면에 z 로 π 돌려 붙여서 잎이 다 넘어가면 월드 좌표와 같아진다. 그래서 펼침면 조각을 "가운데가 x = 0, 페이지 면이 y = 0" 인 한 좌표계로 배치할 수 있다.

**펼침 정도.** `o = min(왼쪽 잎 각도 / π, 1 - 오른쪽 잎 각도 / π)`. 바탕 조각은 `backOut(seg(o, 지연, 지연 + 0.45))` 로 서고(지연 0 ~ 0.55, 앞줄부터), 나중 사건은 `min(win(u, a, b), seg(o, 0.45, 0.95))` 라서 다음 장이 들리기 시작하면 바로 다시 눕는다. backOut 과잉 1.9 라 종이가 수직을 살짝 넘었다가 돌아온다. o 가 0 인 펼침면 조각은 `visible = false`.

**접기 장치(`src/10-paper.js`).**
- flap: 밑변 경첩 하나. `rotation.x = -dir * π/2 * (1 - e)`. 뒷줄 키 큰 조각은 앞으로(dir -1), 버스와 새는 뒤로 눕힌다. 누웠을 때 페이지 밖으로 나가지 않게 경첩 z + 높이가 페이지 반폭 1.6 안에 들게 배치했다.
- vfold: 형상 뒤에 날개 두 장이 세로 주름을 축으로 `±0.95 * e` 벌어진다. 사슴, 고래, 로켓.
- box(평행 접기): 앞면이 서고 지붕은 `-(π - π/2 * e)`, 옆면은 `∓(π - π/2 * e)` 로 앞면 뒤에 겹쳐 있다가 펼쳐진다.
- spring: 폭 0.22, 길이 0.15 조각 7~11개를 지그재그로 잇고 각도 `1.1 * ext`. 끝점에 행성.
- paperPlanet: 원판 세 장을 60도씩 돌려 끼운 종이 오너먼트, 링은 두께 있는 고리.
- 누운 조각이 서로 겹치지 않도록 층마다 y 로 0.0025 씩 띄운다(최대 약 0.04, 잎 사이 여유 0.05 안).

**종이 재질.** 512px 캔버스에 짧은 섬유 획 7,000개(9타일 반복으로 이음매 없음)와 잡티로 높이장을 만들고 세 장의 텍스처로 바꾼다: 색(246 ± 25 회색, 원색에 곱함), 노멀(소벨, 세기 0.55), 거칠기(0.78 ~ 1). UV 가 월드 단위라 결의 크기가 모든 조각에서 같다(0.85 반복/단위). 잘린 면은 같은 색을 흰색 쪽으로 28% 밝혀 색지 단면처럼 보인다. 두께 0.014 ExtrudeGeometry.

**조명.** 톤매핑 없음(원색이 필름 곡선에서 탁해진다), 방향광 2.7 위치 (-5, 9, 9), 반구광 1.75(땅색은 테이블색), PCFShadowMap 2048(모바일 1024) 반지름 3, bias -0.0004, normalBias 0.012.

**카메라.** `CONFIG.shots` 27개 키(목표점, 방위각, 고도, 거리)를 smoothstep 으로 잇고 거리는 로그 보간. 펼침면마다 넓게 → 한쪽으로 돌며 밀착 → 반대쪽 → 넓게 → 장 넘김(고도 58도 위에서). 여기에 0.13Hz 느린 흔들림 2.5도와 포인터(터치 기기는 자이로) 기울기 방위 7도, 고도 4도. 세로 화면은 `0.95 / aspect` 배로 물러선다. 안개 near/far 는 카메라 거리 x 1.6, 4.2.

**성능.** DPR 1.5 상한, 터치 기기 안티에일리어싱 끔, 닫힌 펼침면 조각 숨김, 탭이 숨으면 렌더 건너뜀. 캔버스는 fixed 하나라 화면 밖으로 나가는 일이 없다.

**reduced-motion.** Lenis 끔, 섹션 높이 100vh, 스크롤 위치에서 가장 가까운 펼침면의 완성 상태(`CONFIG.reduceAt`)를 한 장 그리고 바뀔 때만 다시 그린다. 시간 움직임 없음, 표지 글자는 선 상태, 버튼은 처음부터 보임.

## 함정

- `BoxGeometry` 는 재질 그룹이 6개다. `[면, 단면]` 두 개짜리 배열을 주면 인덱스 2~5 면이 안 그려져 스프링이 실처럼 보이고 척추가 사라졌다. 상자에는 단일 재질을 준다.
- 표지 글자 뒤의 V 쐐기를 고정 각도로 두었더니 표지가 넘어간 뒤 아래 페이지를 뚫고 흰 마름모로 튀어나왔다. 쐐기 각도도 글자 서는 정도에 묶었다.
- 잎 높이를 "번호 x 간격" 으로 두면 보드가 두꺼워서 간격이 0.005 만 남아 다른 펼침면의 누운 글자(FOREST 위에 CITY)가 비쳐 보였다. 두께 누적으로 바꾸고, 종이 글자도 닫힌 펼침면에서 숨긴다.
- 고정 안개(10~40)는 세로 화면처럼 카메라가 멀어지면 책 전체를 뿌옇게 덮는다. 거리 비례로 바꿨다.
- 첫 파도 모양(사인 + 2차 고조파)은 산 능선으로 읽혔다. 뾰족한 물마루 `(1 - |sin|)^1.6` + 흰 거품 띠 0.05 로 바꾸니 극장 파도가 됐다.
- 고래가 파도 뒤에 숨어 분홍 조각만 보였다. 1.3 배로 키우고 홈 아래 -1.2 에서 +0.55 까지 올라오게 했다.
- 뒤표지는 반 바퀴 돌아 보이므로 그림을 180도 돌려 붙인다(repeat -1, -1).
- 이미지 프록시는 1536x1024 를 줬고 표지는 거의 정사각이라 가로 66% 를 잘라 쓴다. 표지 그림이 가운데를 비워 두어 POP-UP 글자와 겹치지 않는다.

## 재료

`node tools/gen-images-popup.mjs [이름...]` (ChatGPT OAuth 프록시, 한 장씩, 429 면 60초 대기 후 최대 5회). webp 1024 폭으로 `assets/popup/` 에 둔다. 두 장 모두 WebGL 이 쓰므로 빌드 때 data URI 로 들어간다(HTML 약 210KB).

공통 머리말: `Flat top-down scan of a printed children's book board, cut paper collage made of saturated coloured card stock, visible paper fibre grain, crisp scissor-cut edges with tiny soft drop shadows between layers, bold graphic shapes, no cream, no beige, no kraft brown, no text, no letters, no numbers, no watermark, no logo, fills the whole frame edge to edge.`

| 파일 | 용도 | 프롬프트 요지 |
|---|---|---|
| cover.webp | 앞표지 | 토마토 바탕, 아래 코발트 언덕, 에메랄드 소나무, 해바라기 해, 핫핑크와 딥틸 구름, 가운데는 비움 |
| back.webp | 뒤표지 | 코발트 바탕, 별, 초승달, 작은 행성들, 아래 딥틸 물결 띠 |

그 밖의 조각(나무, 사슴, 건물, 버스, 파도, 고래, 배, 로켓, 행성, 별)은 전부 코드의 경로로 자른 종이다.
썸네일: `assets/thumb/popup.webp` (960x540, 1600x900 바다 펼침면 t = 3.45 화면을 줄임).

## 검증 (2026-09-28)

`python -m http.server 4223` + Playwright. 1440x900, 375x812(터치, DPR 2), reduced-motion, file:// 에서 콘솔 오류 0, 실패 요청 0, 가로 넘침 없음.
1280x720 에서 휠로 조금씩 내리며 40지점(1.5초 대기) 샘플링, 한 색이 95% 넘는 거의 빈 화면 0장. 스크린샷은 세션 scratchpad `lab-popup/`.
