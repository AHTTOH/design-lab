## 방향

작은 언덕 위 나무 한 그루가 일 년을 지난다. 전부 절차 생성 Three.js 이고 이미지 생성은 하지 않았다(재료 0장).
검정 네온도 아니고 크림 바탕도 아니다. 하늘색, 새잎 초록, 호박색 노을, 푸른 그늘이 진 눈이 기본 색이다.
SUMI 의 먹 매화와 겹치지 않게 벚꽃은 사진처럼 밝은 3D 로 그렸다. 먹, 붓, 화선지 느낌은 쓰지 않았다.

## 구조

`js/` 파일은 모듈이 아니라 한 스코프를 나눠 쓰는 조각이다. `build.mjs` 가 순서대로 이어 `<script type="module">` 하나에 넣는다(`file://` 에서 외부 모듈 스크립트가 막히기 때문). 순서는 `build.mjs` 의 `ORDER`.

| 파일 | 하는 일 |
|---|---|
| config.js | 모든 수치와 색. 장면 키, 카메라 키, 계절 키 |
| core.js | 보조 함수, 시드 난수, Lenis, 장면 진행도, 포인터, 스프링 |
| glsl.js | 공용 유니폼 `U`, 공용 GLSL(노이즈, 언덕 높이, 가지 흔들림, 창문 불빛), 수동 그림자 조회, 내장 재질 패치 |
| world.js | 렌더러, 하늘 돔(구름, 별), 언덕, 먼 산, 오두막 |
| tree.js | 공간 식민 알고리즘 가지 생성, 파이프 모델 굵기, 튜브 메쉬, 나무껍질 캔버스 |
| foliage.js | 잎, 꽃(꽃눈 포함), 날리는 꽃잎. 전부 인스턴스 카드 |
| weather.js | 풀, 비, 물웅덩이, 눈, 반딧불이 |
| birds.js | 새 |
| seasons.js | 스크롤 → 연도 시계 → 모든 유니폼, 빛, 하늘 |
| camera.js | 장면별 카메라 키 보간, 한 해 장면 회전 |
| ui.js | 글자 등장, 자석 버튼 |
| main.js | 바람, 돌풍, 루프 |

## 기법과 수치 (전부 `CONFIG`)

**연도 시계.** 모든 계절 상태는 t(0~4, 4에서 한 바퀴) 하나의 함수다. 장면은 자기 진행도를 t 구간으로 옮기고, 그 위에 장면 전용 덧칠(비, 노을, 밤, 새)만 얹는다. 한 해 장면은 t 를 두 바퀴 돌리므로 따로 짠 연출 없이 사계절이 반복된다. 꽃눈은 t 가 4에서 0으로 넘어가기 직전부터 부풀어야 해서 3.5 이후는 t-4 로 잰다.

**나무.** 돔 모양 수관(반지름 6.1, 3.5, 5.7) 안에 끌개 3,200개(모바일 2,400)를 껍질 쪽에 몰아 뿌리고, 줄기를 끌개가 닿을 때까지 기울여 올린 뒤 가지를 키운다. 한 걸음 0.24, 영향 반경 2.0, 제거 거리 0.45, 위로 끌림 0.16. 이웃 찾기는 격자 해시(칸 = 영향 반경)라 생성이 약 85ms 다. 굵기는 파이프 모델(지수 2.3), 밑동은 1.55배로 벌어진다. 위치를 부모와 주 자식 쪽으로 3번 평활해 꺾임을 없앴다. 튜브는 주 자식을 따라가는 사슬마다 하나, 평행 이동 틀로 고리가 꼬이지 않는다. 가는 가지는 끝 고리를 0.3배로 줄여 뭉툭하지 않다.

**가시처럼 보이던 짧은 곁가지.** 곁가지 부분 트리의 마디가 4개 미만이면 나무 메쉬에서 뺀다(`minTwig`). 처음에는 빈 나무가 가시덤불처럼 보였다. 잎과 꽃은 실제로 그려진 마디 사이 선분 위에만 붙인다(`drawn` 플래그). 떠 있는 잎이 없다.

**잎과 꽃.** `InstancedBufferGeometry` 카드 한 장에 인스턴스 속성(위치, 방향, 난수 4개, 흔들림 세기)만 넘기고 자람, 단풍, 낙엽, 착지, 눈에 묻힘을 전부 정점 셰이더에서 계산한다. 잎 모양은 캔버스로 그린 잎맥 있는 흰 잎 텍스처에 인스턴스 색을 곱한다. 알파 테스트 + `alphaToCoverage`(MSAA) 라 가장자리가 부드럽고 네모가 보이지 않는다. 캔버스 픽셀은 미리 곱한 알파라서 그대로 올리고(`premultiplyAlpha`) 셰이더에서 나눈다. 안 그러면 밉맵이 투명한 검정을 섞어 꽃 가장자리가 회색 얼룩이 된다.
- 잎 14,000장(모바일 7,000), 꽃 16,000송이(모바일 7,000), 꽃잎 2,600장(모바일 1,400).
- 낙엽: 잎마다 지연 0~0.86, 떨어지는 시간 0.14. 공중에서 나선, 바람, 회전을 하고 착지 직전 평평하게 눕는다. 착지 좌표는 잎마다 고정이라 포인터 바람이 바뀌어도 쌓인 잎은 움직이지 않는다.
- 쌓인 잎은 눈이 덮으면 작아지고 t 3.5~3.78 에 썩어 없어진다(눈이 녹을 때 다시 나타나던 문제).

**빛.** 커스텀 셰이더는 태양 그림자 맵을 직접 읽는다(패킹 깊이, 3x3 PCF, `textureLod`). 잎이 잎을 가려 수관 안쪽이 어둡고 풀밭에 얼룩 그림자가 진다. 반구광 + 태양 + 역광 투과(잎 0.85, 꽃 0.95)로 역광 잎이 빛난다. 톤매핑 ACES, 노출 1.05.

**눈.** 나무껍질과 지붕은 `normal.y` + fbm 이 문턱을 넘는 곳만 흰색. 문턱이 눈 양에 따라 내려와 윗면부터 쌓인다. 땅은 노이즈 문턱이라 조각조각 덮였다 녹는다. 밤에는 반구광이 짙은 파랑이라 눈 그늘이 푸르다. 오두막 창 불빛은 공용 GLSL `windowLight()` 로 땅, 풀, 웅덩이, 나무에 번진다.

**바람.** 포인터 가로 위치가 화면 좌우 바람 방향, 세로가 앞뒤, 중심에서 멀수록 세다(기본 0.3 + 0.8). 스크롤 속도는 스프링(강성 0.08, 감쇠 0.82)을 거친 돌풍이 된다. 가지, 잎, 꽃, 풀, 꽃잎, 낙엽, 눈이 같은 값을 읽는다.

**한 해 장면.** 카메라 회전과 연도 시계에 `|lenis.velocity|` 를 더한다(회전 0.0009, 시계 0.004, 최대 0.9). 장면 앞뒤 7% 에서 겨울 끝 자세와 다시 봄 첫 자세로 이어 붙인다. 두 자세는 방위각이 정확히 두 바퀴 차이라 이음매가 없다.

**성능.** DPR 1.5 상한, 그림자 맵 2048(모바일 1024), 계절 상태가 0 인 메쉬는 `visible = false` 로 두 패스 모두 건너뛴다. 탭이 숨으면 렌더하지 않는다. 내장 GPU(Radeon 760M) 1440x900 에서 35~44fps.

**reduced-motion.** Lenis 끔, 장면 높이 100vh, 장면마다 정지 화면 하나(`CONFIG.stills`), 시간 고정, 스크롤로 장면이 바뀔 때만 다시 그림. 모든 글자와 버튼이 처음부터 보인다.

## 함정

- **`onBeforeCompile` 로 패치한 내장 재질은 프로그램 캐시 키가 같다.** three 가 함수 소스로 캐시하므로 땅 셰이더가 오두막 재질에 재사용되어 집이 초록색이 됐다. 패치마다 `customProgramCacheKey` 를 따로 준다.
- 캔버스 텍스처의 투명 픽셀은 검정이다. 밉맵에서 가장자리가 어두워진다(위 참고).
- 커스텀 ShaderMaterial 의 인스턴스별 유니폼(`uCrownC`, `uR0` 등)은 GLSL 에 선언이 있어야 한다. 선언을 빠뜨리면 프로그램 전체가 무효가 된다.
- 셰이더 루프 안 `texture2D` 는 D3D 에서 기울기 경고를 낸다. 그림자 조회는 `textureLod` 로 한다.
- 가을 하늘 지평선을 #f6d7a0 으로 두었더니 베이지 바탕이 되었다. 금빛은 해 색(#ffc271)과 낮은 고도로만 내고 하늘은 파랗게 둔다.
- 겨울 카메라가 오두막 뒤를 지나며 지붕이 화면 아래를 가렸다. 오두막을 나무 쪽으로 당기고(반지름 약 8.5) 그 구간 카메라를 높였다.
- Playwright 모바일 프로필(터치)에서는 휠 한 번의 이동량이 달라 누적 계산이 틀린다. 검수 스크립트는 실제 `scrollY` 를 읽으며 내린다.
