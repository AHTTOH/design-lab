# MARBLE RUN 작업 노트

> 작성: 2026-09-29
> 결과물: `marble/index.html` (빌드 결과. 직접 고치지 않는다)
> 원본: `marble/index.src.html` (HTML, CSS) + `marble/src/*.js` (파일 이름 순서대로 이어 붙임) → `node marble/build.mjs`
> 썸네일: `assets/thumb/marble.webp` (960x540, 1600x900 나선 레일 장면 t = 2.55 를 줄임)

## 방향

스크롤로 굴리는 루브 골드버그 구슬 장치. 옻칠한 원목 탁자 위에 색 아크릴, 황동, 크롬 부품이 한 줄로 이어져 있고 구슬 하나가 연쇄 반응을 끝까지 끌고 간다.
배경은 코발트에서 딥틸로 떨어지는 스튜디오 스윕이다. 크림, 베이지, 아이보리는 쓰지 않았다. 탁자는 짙은 체리 원목, 구조물은 토마토와 해바라기 옻칠, 도미노와 실로폰은 무지개 아크릴.
화면 문구는 큰 영단어(MARBLE RUN, ROLL, TOPPLE, FLIP, SPIN, WIND), "스크롤", "목록으로" 뿐이다. 숫자, 카운터, 자간 벌린 눈썹 라벨 없음. 서체는 Unbounded 800, 한국어는 Pretendard Variable.

## 기법과 수치 (전부 `src/00-core.js` 의 `CONFIG`)

**타임라인 하나.** ScrollTrigger 없이 섹션 `offsetTop` 으로 `t = 구간 번호 + 구간 안 진행도` 를 만든다(마지막 구간은 최대 스크롤까지). 모든 사건은 `CONFIG.time` 의 t 구간이고 모든 움직임이 t 의 순수 함수라서 위로 올리면 그대로 되감긴다. 실시간 물리 엔진은 쓰지 않았다. 시계를 쓰는 것은 선풍기 공회전과 현수막 펄럭임뿐이다.

**구르는 구슬(`src/20-track.js` 의 `createActor`).** 구슬마다 다리(leg) 목록을 둔다. 다리는 `{ t0, t1, at(t), mode }` 이고 mode 는 roll(레일, 깔때기), fly(포물선 비행, 실로폰 튕김), carry(시소 컵, 양동이, 투석기 컵에 실려 감). 로드할 때 0.0004 t 간격으로 한 번 적분한다. roll 은 이동 거리 / 반지름 만큼 `위쪽 벡터 × 이동 방향` 축으로 돌리고 fly 는 마지막 회전 속도를 0.85 배로 이어 간다. 결과 위치와 쿼터니언을 배열에 넣고 재생 때는 두 표본 사이를 lerp, slerp 한다. 그래서 되감아도 구슬 속 무늬가 같은 자세로 돌아온다.

**구슬 재질.** MeshPhysicalMaterial transmission 0.82, ior 1.52, clearcoat 1, attenuation 은 유리색. 안에 비튼 꽃잎 3장(불투명, emissive 0.55)을 넣어 회전이 눈에 보이게 했다. transmission 1 에 옅은 색이면 주황 탁자가 비쳐 올리브색이 된다. 0.82 에 짙은 코발트 `#2f64ff` 로 바꿨다.

**레일(`buildRails`).** 구슬 중심 경로 CatmullRom(centripetal) 하나에서 접선, 옆 벡터(접선 × 위), 레일 아래 벡터를 구해 좌우 0.125, 아래 0.13 에 크롬 튜브 두 줄을 만든다. 황동 침목은 InstancedMesh, 해바라기 기둥은 1.3 간격으로 탁자까지. 나선 구간은 기둥 대신 크롬 기둥에서 뻗은 황동 살.

**도미노.** InstancedMesh 한 개(뱀 줄 약 80개 + 파도 판 50개). 한 장마다 시작 시각, 넘어지는 시간(간격 x 4.5), 최종 각도(기대는 1.18rad, 줄 끝 1.46rad)를 두고 앞 모서리를 축으로 `각도 x u²` 만큼 돌린다. 파도 판은 `(열 + |행 - 가운데| x 0.9)` 순서라 V 자로 번진다. t 가 바뀔 때만 행렬을 다시 쓴다. 되감기는 같은 함수를 거꾸로 부르는 것뿐이다.

**톱니.** 이수(18, 12, 22, 10)와 모듈 0.1 로 반지름을 정하고 중심 거리를 반지름 합으로 맞췄다. 맞물림 각도는 `θj = α + π + (α − θi) x ni/nj − π/nj` (α 는 i 에서 j 로 가는 방향)라서 이가 항상 엇갈린다. 첫 톱니 각도는 양동이가 내려간 거리 / 실패 반지름 0.2.

**카메라(`src/85-camera.js`).** `CONFIG.shots` 36개 키(방위각, 고도, 거리, FOV, follow). 목표점은 `p` 와 "지금 일이 벌어지는 점"을 follow 비율로 섞는다. 일이 벌어지는 점은 구슬 A, 넘어지는 도미노의 앞머리, 시소, 구슬 B, 양동이에서 톱니를 거쳐 깃발, 투석기, 쇠구슬 C, 선풍기에서 현수막 순서로 넘겨지고 경계마다 0.04 t 동안 섞어서 튀지 않는다. 거리는 로그 보간, 포인터 위치로 방위 3도, 고도 2도 흔들림.
세로 화면은 가로 시야를 지킨다. 가까운 샷은 가로 FOV 의 92%, 거리 24 이상 풀백은 64% 를 남긴다(전체를 다 넣으면 375px 에서 기계가 너무 작아진다). 거리 1.08 배.

**조명과 후처리.** RoomEnvironment PMREM, 방향광 2.6(PCFSoft 2048, 모바일 1024). 그림자 상자는 카메라 목표를 따라가며 크기가 `거리 x 0.62`(5~26)라서 근접 샷도 그림자가 뭉개지지 않는다. ACES 노출 1.0. UnrealBloom 0.32 / 0.45 / 임계 1.05 를 HalfFloat 합성 타깃(samples 4)에 건다. 임계를 1 넘게 둬야 금속 하이라이트만 번진다.

**성능.** DPR 1.5 상한, 캔버스 하나(fixed), t 와 화면 크기와 포인터 이징이 그대로면 렌더하지 않는다. 선풍기가 돈 뒤(t > 4.99)만 매 프레임 그린다. 탭이 숨으면 루프가 렌더를 건너뛴다.

**reduced-motion.** Lenis 끔, 구간 높이 100vh, t = 6(완성된 기계)을 `CONFIG.still` 시점에서 한 장 그리고 화면 크기가 바뀔 때만 다시 그린다. 구간 단어와 스크롤 안내는 숨기고 제목과 "목록으로"는 처음부터 보인다.

## 함정

- ShaderMaterial 한 줄 문자열 안에 `#include <colorspace_fragment>` 를 넣으면 컴파일 실패. `#include` 는 줄 맨 앞이어야 한다(`\n` 으로 끊는다).
- 크롬 envMapIntensity 2.4 는 레일이 네온관처럼 번진다. 1.25, 거칠기 0.16 에 블룸 임계 1.05 로 낮췄다.
- 현수막을 탁자 앞(z 6.5)에 두었더니 도미노와 시소 근접 샷마다 기둥과 두루마리가 화면 앞을 가렸다. 탁자 뒤(z -5.5)로 옮기고 종과 선풍기도 같이 옮겼다. 마지막 풀백에서 현수막이 기계 뒤 무대 배경처럼 선다.
- 현수막 재질에 sheen 을 주고 블룸 임계가 낮으면 토마토색이 연분홍으로 날아간다. MeshStandard 거칠기 0.86.
- 구슬만 따라가는 비행 샷(시소 발사, 투석기 발사)은 화면 대부분이 배경색이었다. follow 0.55~0.6 에 탁자 쪽 앵커를 섞어 구슬과 기계가 같이 보이게 했다.
- 비튼 꽃잎을 넣어도 transmission 1 이면 거의 안 보인다. 0.82 로 낮추고 emissive 를 올렸다.

## 재료

이미지 생성 없음. 탁자 결은 1024px 캔버스에 흔들리는 결 260줄, 현수막은 2048px 캔버스에 Unbounded 로 쓴 글자. 나머지는 전부 Three.js 기본 도형과 LatheGeometry, ExtrudeGeometry, RoundedBoxGeometry 로 만든 절차 모델이다. `file://` 에서도 그대로 동작한다(외부 이미지 없음).

## 검증 (2026-09-29)

`python -m http.server 4232 --bind 127.0.0.1` + Playwright. 1440x900, 375x812(터치, DPR 2), reduced-motion, file:// 에서 콘솔 오류 0, 실패 요청 0, 가로 넘침 없음. reduced-motion 에서 "목록으로" 포커스 외곽선 4px 확인.
1280x720 에서 휠로 조금씩 내리며 40지점(1.5초 대기) 샘플링, 한 색이 95% 넘는 거의 빈 화면 0장.
되감기: t 0.62, 1.3, 1.62, 3.3, 4.3 을 찍고 한참 아래로 갔다가 다시 올라와 찍은 화면이 픽셀 차 0 이다(아래 지점과의 차는 59~87).
스크린샷은 세션 scratchpad `lab-marble/`.
