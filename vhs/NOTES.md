# VHS 작업 노트

> 작성: 2026-09-28
> 결과물: `vhs/index.html` + `vhs/vhs.css` + `vhs/js/*.js` (빌드 없음. 고친 파일이 곧 결과물이다)
> 재료: `assets/vhs/` (영상 4편 + 스크럽용 재인코딩 1편, 포스터 4장, 채널 스틸 2장), 썸네일 `assets/thumb/vhs.webp`

## 방향

1990년대 비디오테이프와 브라운관 TV. 검정 관, VCR 파란 화면, 형광 초록 OSD, 채도 높은 테이프 색(마젠타, 시안, 노랑, 컬러바).
크림·베이지 종이 톤은 쓰지 않았다. 화면 글자는 VCR 이 띄우는 OSD 말투의 짧은 단어뿐이다(전원, 외부입력, 재생, 표준, 빨리감기, 되감기, 일시정지, 채널, 트래킹, 꺼내기, 전원 끄기).
타임코드, 카운터, 채널 번호, 프레임 번호는 하나도 없다. 채널은 번호 대신 이름(바다, 밤길, 오락실, 수족관, 불꽃놀이, 볼링장)으로 부른다.
서체는 큰 제목 VT323(구글 폰트), 한글 OSD 는 Galmuri11·Galmuri14(jsdelivr `galmuri@2.40.3`, 한글 픽셀 서체). 재생·되감기 같은 기호는 아이콘 폰트 없이 CSS `clip-path` 도형으로 그렸다.

## 구조와 기법 (수치는 각 파일 맨 위 상수 객체에 있다)

**레이어 세 장.** 아래부터 `#picture`(2D 캔버스 하나, 모든 장면의 화면) → 장면 DOM(OSD 글자, 버튼) → `#crt`(WebGL 유리). 유리는 `pointer-events: none` 이라 버튼이 그대로 눌린다.

**file:// 에서도 되는 이유.** WebGL 은 영상이나 이미지를 한 번도 샘플링하지 않는다. 유리 셰이더는 주사선, 곡면 베젤, 비네트, 유리 반사, 잡음, 트래킹 띠를 스스로 만들어 위에 덮기만 한다. 영상 효과는 전부 2D 캔버스의 `drawImage` 와 합성 모드로만 한다. file:// 영상을 2D 캔버스에 그리면 캔버스가 오염될 뿐 그리기는 되고, 픽셀을 읽지 않으니 문제가 없다. 그래서 빌드 단계(data URI 인라인)가 필요 없고 file:// 에서도 효과가 줄지 않는다. 스크립트는 모듈이 아니라 일반 `<script src>` 라 file:// 에서 그대로 읽힌다(최상위 const 는 파일끼리 공유된다).

**테이프 파이프라인(`js/tape.js`).**
- 그림은 가로 최대 960px 로 작게 그리고 늘려 붙인다. VHS 는 원래 흐리고 슬라이스 효과도 싸진다.
- 원본을 자르지 않고 contain 으로 그린다. 그래서 Flow 반짝이 워터마크(우하단)가 어떤 화면비에서도 보인다. 남는 위아래는 같은 프레임을 48px 폭 버퍼에 줄였다가 cover 로 키운 흐린 복사본(불투명도 0.5)으로 채운다. 세로 모바일에서도 검은 빈칸이 없다.
- 3px 가로 슬라이스마다 사인 두 개로 흔든다(기본 폭의 0.12%, 최대 스트레스에서 +1.2%). 트래킹 띠(높이 7%) 안은 해시로 좌우 찢김 최대 폭의 7%.
- 색 번짐: 폭 14% 로 줄인 채도 1.7배 복사본을 폭의 0.6% 오른쪽으로 밀어 `globalCompositeOperation: 'color'` 로 덮는다. 밝기는 날카롭게 남고 색만 번진다. VHS 가 색 신호를 좁은 대역으로 싣는 원리 그대로다.
- RGB 분리: 1px 이상일 때만. 채널별 버퍼에 `multiply` 로 빨강·초록·파랑만 남기고 `lighter` 로 좌우로 어긋나게 더한다.
- 테이프 스트레스: `|lenis.velocity| * 0.035` 를 0~1 로 자르고 오를 땐 0.25, 내릴 땐 0.06 으로 따라간다. 빠르게 내릴수록 화면이 망가지고 멈추면 천천히 회복한다.

**CRT 유리(`js/crt.js`).** 풀스크린 삼각형 하나. 배럴 곡률 0.05 로 좌표를 휘고 그 좌표로 주사선(3 CSS px 주기, 어둡기 0.3)을 그어 주사선이 곡면을 따라 휜다. 곡률 때문에 밀려난 가장자리가 둥근 모서리(반지름 0.1) 베젤이 된다. 출력은 premultiplied 알파의 over 합성을 차례로 쌓는다(잡음 → 트래킹 띠 → 주사선 → 험 바 → 비네트 → 반사 → 베젤).
장면은 매 프레임 `FX` 객체(static, band, bandY)에 값을 올리고, 유리는 모든 장면이 그린 뒤 마지막에 읽는다(렌더 틱을 가장 늦게 등록).

**스크럽(`js/s3-rewind.js`).** `ffmpeg -g 1 -keyint_min 1 -sc_threshold 0` 로 모든 프레임을 키프레임으로 다시 인코딩(960x540, crf 27, 2.1MB). 탐색 중이면 새 탐색을 걸지 않고 `seeked` 에서 최신 목표로 다시 맞춘다. http(s) 에서는 `fetch` → Blob URL 로 통째로 올려 서버 Range 지원과 상관없이 어디든 탐색된다(python http.server 는 Range 를 모른다). file:// 은 fetch 가 막히므로 `src` 를 그대로 쓴다(파일은 원래 탐색이 된다). 방향은 속도 부호, |속도| < 0.6 이 0.26초 지속되면 일시정지.

**녹아내림(`js/s5-eject.js`).** 폭 1.4% 기둥마다 속도(시드 난수 60% + 사인 40%, 이웃끼리 비슷해 커튼처럼 흐른다)만큼 아래로 밀고, 생긴 틈은 맨 윗줄 2px 을 늘려 채워 색 줄기가 남는다. 글리치 블록은 90ms 마다 시드가 바뀌는 난수로 최대 70개, 25% 는 `color` 합성 색 블록. 컬러바는 16x9 칸마다 문턱을 달리해 한 칸씩 바뀐다.

**전원 끄기(`js/s6-off.js`).** 세로 0.006 배까지 접으며 `lighter` 로 하얗게 달구고, 가로로 접은 뒤 방사형 점 하나로 사라진다. 번인은 28x16 버퍼에 그린 컬러바를 키워 흐리게(불투명도 0.24), 잔상 VHS 는 초록 0.36 + blur 1.5px.

**성능.** DPR 1.5 제한(유리), 그림은 가로 960px 제한. 보이는 장면만 그린다(ScrollTrigger onToggle). 영상은 원하는 장면이 있을 때만 재생하는 참조 집합(`want`)으로 관리해 같은 영상을 두 장면이 써도 꼬이지 않는다.

**reduced-motion.** Lenis 끔, 영상은 재생하지 않고 포스터만 그린다(스크럽 장면도 포스터), 전원 켜기 애니메이션 생략, 잡음·흔들림 시간 변화 없음, 화면은 스크롤이 있을 때만 다시 그린다. 배율 0.4.

## 함정

- 유리 셰이더의 잡음 해시에 `floor(time * 50) * vec2(17, 31)` 같은 큰 오프셋을 더하면 mediump 에서 정밀도가 무너져 잡음이 세로 줄무늬가 된다. 오프셋을 `fract` 로 작게 유지하고 highp 가 있으면 쓴다.
- 트래킹 띠 위치는 2D 캔버스(위가 0)와 `gl_FragCoord`(아래가 0)의 방향이 반대다. `FX.bandY` 는 위 기준으로 두고 셰이더에 `1 - bandY` 로 넘긴다.
- 전원이 선으로 접히는 순간은 화면 대부분이 검정이라 빈 화면 판정에 걸렸다(40지점 중 1곳). 번인을 접히는 동안(0.14~0.34) 먼저 깔아 해결했다.
- 되감기 큰 OSD 를 아래에 두었더니 일시정지 잡음 띠(높이 86%)와 겹쳤다. 세로 가운데로 옮겼다.
- 코너 비네트 때문에 좌상단 작은 OSD 가 어두워 보였다. 여백을 8vw·10vh 로 넓히고 글로를 두 겹으로 했다.
- 스크롤을 멈추고 찍으면 되감기 장면은 늘 "일시정지"다. 빨리감기·되감기 연출은 휠을 굴리는 중에 찍어야 보인다.
- 로컬 python 서버가 가끔 `ERR_CONNECTION_REFUSED` 를 냈다(영상 요청이 몰릴 때). 재실행 두 번은 깨끗했다. 배포 주소에서는 해당 없음.
- Playwright 가 WebGL 에서 "GPU stall due to ReadPixels" 경고를 찍는다. 스크린샷 캡처 때문에 나는 드라이버 경고라 오류가 아니다.
