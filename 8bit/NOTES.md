# 8BIT 작업 노트

> 작성: 2026-09-28
> 결과물: `8bit/index.html` (단일 파일, 빌드 없음), 썸네일 `assets/thumb/8bit.webp` (960x540)

## 방향

스크롤이 곧 컨트롤러인 8비트 횡스크롤 게임. 스크롤을 내리면 작은 픽셀 주인공이 오른쪽으로 달리고, 올리면 왼쪽으로 뒤돌아 달린다.
구덩이, 적, 블록 앞에서는 정해진 지점에서 알아서 점프한다. 동전은 지나가는 순간 반짝이며 터지고 화면 왼쪽 아래 금화 더미로 날아가 쌓인다.
숫자(점수, 동전 개수, 목숨, 시간)는 화면 어디에도 없다. 모은 양은 더미의 크기로만 보인다.

모든 그림은 코드로 그렸다. 스프라이트는 문자열 격자(주인공 12x16, 적 12x12, 동전 8x8), 타일과 배경은 캔버스 절차 생성이다.
이미지 생성, 외부 스프라이트, 소리는 쓰지 않았다.

글자는 Press Start 2P(영문 큰 단어), 한국어는 Pretendard Variable("스크롤", "목록으로" 두 곳).
DotGothic16 은 한글 글리프가 없다(Google Fonts `text=스크롤` 서브셋이 1.6KB 빈 폰트로 온다). 그래서 쓰지 않았다.

## 월드 (배율 적용 전 vh, `:root --scroll-stretch: 1`)

| 섹션 | --len | 내용 | 다음 월드로 |
|---|---|---|---|
| GREEN HILLS | 1300vh | 밝은 하늘색 하늘, 설산, 구름, 초록 언덕, 덤불. 8BIT 제목 아래 주인공이 서 있다가 달리기 시작 | 초록 파이프로 들어가 아래로 워프 |
| CRYSTAL CAVE | 1300vh | 천장에서 내려온 파이프로 떨어진다. 종유석, 빛나는 수정과 버섯, 포자, 물방울, 박쥐 | 스프링을 밟고 천장 구멍으로 튀어 오름 |
| SNOW PEAKS | 1200vh | 눈 구멍에서 튀어나온다. 오로라, 별, 설산, 눈 덮인 전나무, 눈사람, 눈발 | 얼음 구멍으로 떨어짐 |
| LAVA KEEP | 1300vh | 성 천장 구멍으로 떨어진다. 불빛 아치 창, 기둥과 붉은 깃발, 횃불, 쇠사슬, 용암 구덩이와 튀어 오르는 불덩이, 불티 | 덩굴이 자라고 타고 올라감 |

## 기법과 수치 (전부 `CONFIG`, `WORLDS`, `LINKS` 에 있다)

- 스크롤: Lenis 1.1.13 lerp 0.08, 자체 rAF 에서 `lenis.raf`. GSAP 과 ScrollTrigger 는 쓰지 않았다. 스크롤 위치 하나로 월드, 진행도, 전환을 계산한다.
- 픽셀 해상도: 가로 화면은 가상 높이 약 224행, 세로 화면은 가상 폭 약 160열이 되게 정수 배율 S 를 고른다(`round(기기 픽셀 / 목표)`). 캔버스는 가상 해상도 그대로 만들고 CSS 크기를 `가상 x S / DPR` 로 줘서 기기 픽셀 기준 정확히 정수 배가 된다. `image-rendering: pixelated`, 모든 컨텍스트 `imageSmoothingEnabled = false`. 1280x720 은 427x240(3배), 1440x900 은 360x225(4배), 375x812 DPR2 는 150x325(5배, 주인공이 약 40px 높이).
- 월드 진행: 각 섹션 안에서 앞뒤 75vh 를 전환에 쓰고(`edgeVh`), 그 사이를 경로 길이에 선형으로 맞춘다. GREEN HILLS 만 첫 30vh 동안 제자리(`titleHoldVh`).
- 경로: 레벨 스크립트(r 달리기, c 동전 줄, p 구덩이, e 적 넘기, s 밟기, f 머리 위 비행체, u/d 단차, P 공중 발판, q 보석 블록, i 파이프, x 기둥)가 지형과 주인공 경로를 함께 만든다. 경로는 걷기, 점프(2차 베지어, 정점 = 낮은 쪽 - a), 낙하(y 가 u²), 세로(깃대 미끄럼) 조각으로 되어 있고 호 길이 s 로 매개화한다. 점프 길이는 가로 x 1.15 + 높이 x 0.5 라서 점프 구간은 스크롤을 조금 더 먹는다.
- 동전, 적 밟기, 블록 두드리기는 전부 s 기준으로 판정한다. 스크롤을 되감으면 동전이 다시 나타나고 더미가 줄어든다. 앞으로 지나갈 때만 반짝임 9개 + 더미로 날아가는 동전(0.65초 호)이 생긴다. 한 프레임 최대 10개.
- 달리기: 발 동작 프레임은 이동 거리 5px 마다 넘어간다(run1, run2, run3, run2). 스크롤 속도가 곧 다리 속도다. `lenis.velocity` 가 3 을 넘으면 발밑 먼지, 11 을 넘으면 뒤에 청록 잔상 두 개. 멈추고 0.25초 지나면 대기 자세, 3.4초마다 눈 깜빡임, 4.5초 뒤엔 좌우를 둘러본다.
- 카메라: x 는 주인공에 고정(가로 화면 38%, 세로 42%), y 는 발 높이를 화면 64%(세로 60%)에 둔다. 점프 중에는 출발과 착지 높이를 선형 보간한 값을 따라가서 점프마다 화면이 출렁이지 않는다.
- 시차: 월드마다 3~4겹 띠(폭 512px, 사인과 삼각파 주기를 정수로 맞춰 이음매 없음). 가로 계수 0.08~0.62, 세로 계수는 `0.35 + 0.65 x 가로 계수`(가까운 층이 단차를 따라와야 층 사이가 벌어지지 않는다). 구름 층은 초당 3~9px 흐른다.
- 하늘: 색 띠 5~7단, 경계마다 체크 디더 두 줄.
- 전환: 두 월드를 세로로 쌓고 카메라가 `화면 높이 + 띠(화면 50%)` 만큼 이동한다(`pan` 0.18~0.82). 띠 위쪽 반은 위 월드의 흙, 아래쪽 반은 아래 월드의 천장이나 하늘. 주인공은 앞 월드 출구에서 다음 월드 입구까지 직선으로 이동한다(`travel` 0.06~0.94). 파이프는 주인공을 가리고, 굴은 띠 안에 어두운 수직 통로와 빛줄기, 덩굴은 전 구간, 구름 낙하는 연결물 없음. 빈 화면이 생길 틈이 없다.
- 금화 더미: 모래더미 시뮬레이션(가운데에 떨어뜨리고 양옆 높이 차가 2 넘게 낮으면 굴러감)으로 칸을 미리 정한다. 동전 5x4, 칸 간격 가로 3px(세로 화면 2px), 층 2px.
- 피날레: 진행도 0.56~0.66 에서 세계를 화면 18% 아래로 내려 하늘을 비운다. 0.58~0.68 성 깃발 상승, 0.5 부터 불꽃(0.16~0.45초 간격, 불꽃 26~40개, 속도 34~62, 중력 50, 수명 1.1~1.7초, 끝 25% 는 깜빡임), 0.64~0.7 CLEAR 타자, 0.72 버튼.
- 화면 글자: 월드 이름은 타자기처럼 한 글자씩 켜지고 꺼진다(섹션 0.07~0.1 에서 켜짐, 0.2~0.23 에서 꺼짐). Press Start 2P 는 8px 격자라 크기를 8의 배수(160, 120, 96, 56, 40, 24px)로만 쓴다. 외곽선은 1/16em 8방향 + 2/16em 드롭.
- 자석 버튼: 포인터 편차 x 0.4 를 0.18 로 따라가고 2px 단위로 끊어서 움직인다. 포커스는 흰 점선 4px.
- 멈춤: 탭이 숨으면 프레임을 건너뛴다. 캔버스는 화면 고정이라 늘 보인다.
- reduced-motion: Lenis 끔, 섹션 높이 100vh, 화면 가운데에 걸린 월드의 정지 장면(경로 42% 지점, 피날레는 성문 앞)을 스크롤이나 리사이즈 때만 다시 그린다. 불꽃은 멈춘 고리 4개. 모든 단어와 버튼이 그대로 보인다.

## 함정

- `sprite()` 는 팔레트에 없는 글자를 만나면 예외를 던진다. 조용히 넘어가면 투명 픽셀로 빠져서 스프라이트가 깨진 줄 모른다.
- 16진 색 하나를 7자리로 잘못 쓰면 캔버스는 오류 없이 이전 색을 쓴다. LAVA KEEP 흙 반점에서 실제로 걸렸다.
- 구덩이 안은 배경 띠의 아래 색이 그대로 보여서 설원 구멍이 밝은 기둥처럼 보였다. 월드마다 `pit` 색을 두고 왼쪽 가장자리 높이부터 채운다(하늘 월드는 구름이라 없음).
- 무지개 띠의 구름을 한 번만 찍으면 띠 이음매에서 반쪽 구름이 보인다. 가로 -512, 0, +512 세 번 찍는다.
- 깃발이 깃대 왼쪽이면 미끄러지는 주인공에 가려진다. 깃발은 오른쪽.
- 세로 화면에서 금화 더미가 버튼과 겹친다. 세로 화면은 칸 간격 2px, 버튼은 오른쪽 정렬.
- 불꽃과 CLEAR 가 성 탑과 겹쳐서 피날레에서만 세계를 아래로 내린다.
- Lenis 가 붙은 페이지도 `scrollTo` 로 옮기면 따라온다. 검수 스크린샷은 휠로 천천히 내리고 1.5초 기다린 뒤 찍는다.

## 재료

이미지 생성 없음. 주인공, 적, 동전, 불덩이는 문자열 스프라이트, 타일, 배경, 장식, 성, 깃대, 덩굴, 파이프는 전부 캔버스 절차 생성이다.
썸네일은 1920x1080 에서 SNOW PEAKS 장면을 찍어 최근접 보간으로 960x540(정확히 1/2) 줄인 webp(품질 85).

## 검증 (2026-09-28)

`python -m http.server 4222` + Playwright. 1440x900, 375x812(터치, DPR 2), reduced-motion(1440, 375), file:// 각각 콘솔 오류 0, 실패 요청 0, 가로 넘침 없음.
1280x720 에서 휠로 천천히 내려 균등 40지점을 1.5초씩 기다려 찍고, 한 색이 95% 넘는 화면을 셌다. 0장이다. 한 색이 가장 많이 차지한 화면도 39% 였다.
스크린샷은 세션 scratchpad `lab-8bit/`.
