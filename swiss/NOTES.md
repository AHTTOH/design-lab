# SWISS 작업 노트

> 작성: 2026-09-28 (Opus 5.5 서브에이전트)
> 대상: `swiss/index.html` (단일 파일, 빌드 없음), 썸네일 `assets/thumb/swiss.webp`
> 루트 `index.html` 목록과 `README.md` 구성표 연결은 통합 담당이 한다. 이 폴더 밖의 공유 파일은 건드리지 않았다.

## 콘셉트

AFTER DARK 연작의 반대편. 스위스 국제 타이포그래피 양식이다.

- 색: 순백 `#ffffff`, 순흑 `#000000`, 신호 빨강 `#ff2a00` 하나. 전부 `:root` 토큰(`--paper`, `--ink`, `--signal`, `--rule`)이고 JS 는 색을 직접 쓰지 않는다(키네틱 장면만 토큰을 읽어 보간한다).
- 서체: Archivo 가변(Google Fonts, 굵기 100~900, 너비 62~125) + Pretendard Variable.
- 12 x 12 모듈 격자(가로 12단, 세로 12행) 위에 모든 배치가 좌표로 적혀 있다. 좌측 정렬, 오른쪽은 흘린다.
- WebGL 없음. SVG, CSS transform, DOM 만 쓴다. 이미지 생성도 하지 않았다(타이포그래피만으로 충분하다고 판단).

## 엔진

- 스크롤: Lenis 1.1.13 `lerp 0.08` + GSAP 3.12.5 ScrollTrigger, AFTER DARK 와 같은 배선.
- `mountScene(sel, scene, still)`: 장면마다 `p`(핀 진행도)와 `e`(섹션이 아래에서 올라오는 동안의 진입 진행도)를 준다. 보이는 장면만 매 틱 다시 그린다(속도 스프링 때문). 격자 선, 원 장면의 호, 견본 글자 페이드는 `e` 로 그려서 장면 첫 화면이 비지 않는다.
- 속도 스프링: 목표 `clamp(lenis.velocity * .02, -1, 1)`, 강성 .085, 감쇠 .8(V 의 녹는 글자와 같은 값). 포스터 글자 skew 9도, 격자 글자 7도, 키네틱은 안 붙은 단어 회전 30도와 세로 90px, 붙은 단어 skew 12도, 원 장면 그룹 회전 6도, 견본 너비 축 -30.
- 포즈 엔진(`resolveFrame`, `placeRun`, `stage`, `createComposer`): 프레임은 격자 단위 `{id, x, y, w, h}` 또는 글자 묶음 `{run:[...]}` 이다. 글자는 캔버스 `measureText` 의 잉크 상자로 크기를 맞추고 상자 바닥에 기준선을 둔다. `r: -90` 이면 아래에서 위로 읽히게 상자 오른쪽 아래에 붙는다. 프레임 사이 이동은 요소마다 시차(`spread`)를 준 cubic in-out. 가로 화면 `L`, 세로 화면 `P` 프레임을 따로 적었다. 프레임에 요소가 빠지면 예외를 던진다.
- 텍스트 블록(줄 모양 회색 본문)은 두께 3px, 간격 8px(모바일 2px, 6px) 막대. 7줄마다 문단 끝 줄은 짧게, 한 줄은 비운다. 시드 PRNG 라 매번 같은 모양이다.

## 장면별 수치

- 포스터: 전환 창 `[.1,.24] [.32,.46] [.54,.68] [.76,.9]`, 시차 .35. 로드 직후 1.9초 동안 격자 선이 그려지고 글자가 2.5행 아래에서 올라온다(스크롤과 무관한 유일한 모션).
- 격자: 진입 `[.03,.12]`, 이후 `[.27,.37] [.44,.54] [.61,.71] [.78,.88]`. 첫 프레임은 두 번째 프레임을 높이 0, 투명도 0 으로 복제해 만든다(블록이 위에서 아래로 자란다).
- 키네틱: 단어 붙기 `[.05,.52]`, 한 단어에 .1. 재배치 `[.6,.74]`. 번역과 출처 `[.76,.84]`. 흩어진 단어는 격자 칸에 맞춘 위치, 회전 0, 90, -90 중 하나, 크기 .28~.95배, 투명도 .16. 세로 화면은 7줄 조판을 세로 가운데에 둔다.
- 원과 막대: 막대 진입 `[.12,.36]`(이동 거리 4 정사각형 단위), 원 등장 `[.3,.5]` backOut, 조립(그룹 -30도에서 0도, 원이 막대 위 음표 자리로) `[.52,.72]`, 빨간 원 낙하 `[.76,.9]`. 호는 둘레의 .78 만 그리고 스크롤 동안 140도 돈다. 막대 왼쪽 끝은 가로 화면에서 3단 선, 세로 화면에서는 화면 밖.
- 견본: 경로 `(굵기, 너비)` = 0 (100,100) → .26 (900,100) → .34 (900,125) → .48 (900,62) → .6 (300,62) → .72 (300,125) → .84 (800,100). 폭포 줄마다 .035 늦게 따라간다. 글자 크기는 가장 넓은 축(900, 125)에서 폭을 재서 정하므로 축이 어떻게 움직여도 넘치지 않는다.
- 마무리: 낙하 `[.03,.34]`, 막대 `[.32,.42]`, 한글 `[.38,.48]`, 원 버튼 `[.46,.58]`, 격자 흐려짐과 막대 두꺼워짐 `[.72,.92]`. 자석 끌림 .35, 라벨 .18.

## reduced-motion

Lenis 끔, 장면 높이 auto, 핀은 100vh 한 장. 각 장면은 `still` 진행도 한 장으로 그린다(포스터는 첫 구성, 나머지는 마지막 구성). 진행 막대와 스크롤 안내 숨김. 문서 높이 5,400px.

## 함정

- `vector-effect: non-scaling-stroke` 와 `pathLength=1` 대시를 같이 쓰면 크롬에서 호가 점선으로 부서진다. 호 선 두께를 `1.25 / 정사각형 크기` 로 직접 넣어 해결했다.
- 막대를 정사각형 단위로 고정 길이(-0.3~1.3)로 두면 가로 화면 중간에서 뚝 끊겨 보인다. 픽셀 기준(격자 3단 선에서 화면 오른쪽 너머까지)으로 계산해 정사각형 단위로 되돌린다. 그러면 진입 이동 거리도 막대 길이보다 길어야 한다(4).
- 장면 시작(`p = 0`)에 모든 요소가 0 에서 시작하면 섹션이 올라오는 동안 흰 화면만 보인다. 진입 진행도 `e` 를 따로 만들어 해결했다.
- 캔버스 폰트 측정 전에 `document.fonts.load` 로 Archivo 900 과 Pretendard 900(쓰는 한글 글자 목록)을 먼저 받는다. 안 받으면 잉크 상자가 대체 서체 기준이 된다.
- 세로 화면 키네틱은 `guarantee.` 폭이 글자 크기를 정해 조판이 작아진다. 줄을 늘려도 커지지 않는다(하이픈 분철을 하지 않는 한).
