# 인수인계서: AFTER DARK 퀄리티 재현법

> 작성: 2026-09-28 (Opus 5.5 세션, StateProof 해커톤 제출 직후 디자인 연습)
> 목적: 다음 세션이 이 레포나 다른 프로젝트에서 같은 수준의 인터랙션 페이지를 다시 만들 수 있게 한다.
> 결과물: `stardust/`, `after-dark-1/`, `after-dark-2/`, `after-dark-3/`. 공개 주소 https://ahttoh.github.io/design-lab/

## 0. 한 줄 요약

신영환이 "좆된다, 이거지"라고 반응한 지점은 **스크롤에 묶인 실시간 그래픽**(셰이더, 파티클 모프, 영상 리빌)이다. 정적인 카드 레이아웃은 아무리 다듬어도 그 반응이 안 나온다.
그래픽의 재료(이미지·영상)는 전부 직접 생성했다. 재료 생성이 막히면 퀄리티가 바로 떨어진다.

## 1. 신영환 취향 (실제 발언에서 뽑음)

좋아한 것
- 스크롤을 내리면 화면이 반응하는 연출. "1번 사이트처럼 스크롤 내리면 애니메이션 되는 거"
- 별가루가 휠을 따라오는 것, 파티클이 모양을 바꾸는 것, 글자가 해독되듯 바뀌는 것
- **길게 내려야 끝나는 페이지.** "스크롤 한 1분은 드르륵 내려야 끝날 정도로"
- 영상을 배경으로 쓰는 것. "동영상 팍팍 써도 돼"
- 검정 바탕 + 원색 계열 네온(코발트, 바이올렛, 마젠타, 라임)

싫어한 것
- **장면이 너무 빨리 넘어가는 것.** "스크롤 한두 번 만에 졸라 큰 폰트들이 슉슉 바뀌어 버려서" → 장면 하나에 최소 350vh 이상 준다
- 크림·아이보리·회백색 배경 (레퍼런스 3번 DarkPool 을 "제일 좆같다"고 함)
- 밋밋한 것, AI 가 만든 티가 나는 것, "16:9 피피티 슬라이드 느낌"
- 긴 부연 설명 문장. 화면에 안내문·부제를 자동으로 붙이지 않는다(`claude-rules/rules/web/design-quality.md` 1절)

## 3. 작업 순서 (이 순서가 퀄리티를 만들었다)

1. **재료부터 만든다.** 코드 전에 이미지 4~7장, 영상 3개를 생성한다(4절). 재료 없이 CSS 그라데이션으로 때우면 바로 AI 슬롭이 된다.
2. **장면 목록을 먼저 쓴다.** 장면마다 이름, 길이(vh), 핵심 기법 하나. III 은 14장면, 총 약 6,600vh(데스크톱 66화면)다.
3. **장면 하나에 대담한 기법 하나.** 한 장면에 셰이더와 파티클과 영상을 다 넣지 않는다.
4. **sticky + progress 패턴으로 만든다**(5절). 장면 길이만 바꿔서 템포를 조절한다.
5. **Playwright 로 스크린샷을 찍어 스스로 본다**(7절). 데스크톱, 375px 모바일, reduced-motion 세 조건.
6. 신영환에게 보여 주고 "더 해봐"가 나오면 장면을 늘리고 길이를 늘린다. 줄이지 않는다.

## 4. 재료 생성

### 이미지: ChatGPT OAuth 프록시 (API 비용 0원)

```
npx openai-oauth --port 10531          # 백그라운드
node tools/gen-images-1.mjs            # I·II 용 chrome, glass, orb, bloom
node tools/gen-images-2.mjs            # III 용 eclipse, jelly, mask + 영상 포스터 스틸
ffmpeg -i x.png -q:v 80 x.webp         # 레포에는 webp 만 둔다
```

프롬프트 공통 머리말이 톤을 통일한다. 그대로 재사용한다.
- 오브제: `Editorial studio photograph, pure black background, dramatic rim lighting, ultra detailed, no text, no letters, no watermark.`
- 장면: `Cinematic film still, pure black background, dark moody, ultra detailed, 35mm, no text, no letters, no watermark, no logo.`
- 색은 항상 코발트, 바이올렛, 마젠타 중에서 지정한다. 배경은 항상 pure black.

### 영상: Google Flow (신영환 AI Pro 구독, 한 편 12크레딧)

```
node tools/flow-video.mjs gen assets/video/v4.mp4 "<프롬프트>" "<파일명 키워드 정규식>"
```

- 브라우저 확장으로 labs.google 에 들어가지 않는다. 확장 권한이 막혀 있다. 반드시 이 스크립트(instafactory 의 CDP 파이프라인 재사용)로 한다.
- 전용 크롬 프로필에 로그인이 저장돼 있다(`instafactory/factories/shorts/data/video/`). 크롬 창이 하나 뜬다.
- 프롬프트 규칙: 검정 배경, `static camera` 또는 `slow motion`, `no text`. 느리게 움직이는 것(연기, 성운, 액체 금속, 오로라)이 루프 배경으로 좋다.
- 720p·8초로 만들고 `loop muted playsinline` 으로 돌린다. 포스터는 `ffmpeg -i v.mp4 -frames:v 1 -q:v 80 v.webp`.

## 5. 기법 레시피

### 스크롤 엔진 (전 페이지 공통)

```js
gsap.registerPlugin(ScrollTrigger);
const lenis = reduce ? null : new Lenis({ lerp: 0.08 });
if (lenis) { lenis.on('scroll', ScrollTrigger.update); gsap.ticker.add((t) => lenis.raf(t * 1000)); gsap.ticker.lagSmoothing(0); }
```

- CDN: `gsap@3.12.5`(gsap, ScrollTrigger), `lenis@1.1.13`, `three`. 폰트 Pretendard Variable.
- `lenis.velocity` 를 스크롤 속도로 쓴다. 마키 속도, 워프 늘어짐, 별가루 꼬리가 전부 이 값 하나에 묶여 있다. **속도에 반응하는 것**이 "살아 있다"는 느낌의 핵심이다.

### sticky 장면 패턴 (III 의 뼈대)

```html
<section class="scene" style="--len:500vh"><div class="sticky">...</div></section>
```
```css
.scene { position: relative; height: var(--len); }
.sticky { position: sticky; top: 0; height: 100vh; overflow: hidden; }
```
```js
ScrollTrigger.create({ trigger: el, start: 'top top', end: 'bottom bottom', onUpdate: (s) => draw(s.progress) });
```

- 장면 안에서는 `seg(p, a, b)` 로 구간을 자르고 `smooth()` 로 이징한다. 타임라인 라이브러리 없이 progress 하나로 모든 걸 그린다.
- III 장면 길이: AURORA 200vh, MORPH 1200vh, FOG 350vh, KINETIC 550vh, DIVE 500vh, PORTAL 400vh, DRIFT 500vh, PIXEL SORT 500vh, SPLIT 450vh, WARP 500vh, FAN 450vh, COUNT 350vh, 끝 650vh.
- 변신이 여러 번 일어나는 장면(MORPH, 6단계)은 1200vh 를 준다. 한 단계에 200vh 꼴이다.

### WebGL 렌더러 하나를 여러 장면이 나눠 쓴다

- 캔버스 하나를 fixed 로 깔고 `modes` 맵에 장면별 scene/camera 를 등록한다. 보이는 장면만 렌더한다(`onVisible` 토글). 장면마다 캔버스를 만들면 모바일에서 컨텍스트가 터진다.
- `setPixelRatio(Math.min(devicePixelRatio, 1.5))`, `antialias: false`.

### 파티클 모프 (II 8,000개, III 10,000개)

- 모양마다 목표 좌표 배열을 미리 만든다(구, 은하 나선, 토러스 매듭, 글자는 캔버스에 텍스트를 그려 픽셀을 샘플링, 하트, 얼굴은 이미지 밝기로 샘플링).
- ShaderMaterial 에 `aFrom`, `aTo` 속성을 주고 progress 로 mix 한다. `blending: THREE.AdditiveBlending`, `depthWrite: false` 여야 빛나는 느낌이 난다.
- 전환 중간에 노이즈로 흩어졌다 모이게 하면 "변신" 느낌이 산다.

### 그 밖의 기법과 위치

| 기법 | 위치 | 요점 |
|---|---|---|
| 오로라 풀스크린 셰이더 | I 히어로, III AURORA | fbm 노이즈 + 시간 + 포인터. 쿼드 하나에 프래그먼트 셰이더 |
| 글자 흩어짐 | I, III 히어로 | 글자를 `.ch` span 으로 쪼개고 progress 로 랜덤 방향 이동·회전 |
| 텍스트 스크램블 | II, III MORPH 캡션 | 글자마다 시작·끝 프레임을 랜덤으로 주고 그 사이엔 가타카나·기호로 교체 |
| 속도 마키 | I, III | 기본 속도 + `lenis.velocity` 가산, 방향도 따라감 |
| 가로 갤러리 | I, III DRIFT | pin + x 이동, 카드에 포인터 틸트와 글레어 |
| 줌 터널 | II, III DIVE | CSS 3D `translateZ` 층을 progress 로 앞으로 당김 |
| RGB 분리 | II | SVG `feColorMatrix` 로 채널 분리 후 오프셋, 속도에 비례 |
| 원형 포털 영상 리빌 | III PORTAL | `clip-path: circle(r at x y)`, 중심은 커서 위치, 반지름은 progress |
| 화면 분할 리빌 | III SPLIT | 위아래 두 판이 갈라지며 뒤의 영상이 드러남 |
| 픽셀소트 전환 | III PIXEL SORT | 셰이더에서 밝기 임계값 기준으로 세로 방향 샘플을 끌어내림 |
| 별가루 커서 | 전 페이지 | 포인터 이동마다 입자 4개, 중력 0.05, 수명 감소 0.018, shadowBlur 10 |
| 워프 | STARDUST, III WARP | 이전 프레임을 반투명 검정으로 덮어 꼬리를 남기고, 속도가 크면 점 대신 선 |
| 진행 막대 + HUD | III | 전체 progress 는 scaleX, 현재 장면 번호·이름 표시 |

영상은 보일 때만 재생한다(`onVisible` 에서 play/pause). 전부 동시에 돌리면 모바일이 버벅인다.

## 6. 함정 (전부 실제로 걸림)

- **`file://` 로 열면 WebGL 이 외부 이미지를 못 읽는다**(캔버스 오염). 셰이더·샘플링에 쓰는 이미지는 빌드 때 data URI 로 넣는다 → `after-dark-3/build.mjs`. `index.html` 을 직접 고치지 말고 `index.src.html` 을 고친 뒤 빌드한다.
- Flow 에 공지 팝업("시작하기")이 새로 뜨면 원 파이프라인이 멈춘다. 720p 타일에는 `.resolution-badge` 가 없어서 완료 감지도 실패한다. `tools/flow-video.mjs` 가 둘 다 우회한다. 실패로 끝나도 영상은 만들어져 있을 수 있으니 `download` 모드로 받아 본다(크레딧 절약).
- 로마 숫자 I 같은 굵은 글자에 `-webkit-text-stroke` 만 주면 깨진 글자(□)처럼 보인다. 채운 색을 쓴다.
- `html, body { overflow-x: clip }` 을 넣지 않으면 흩어지는 글자와 틸트 카드 때문에 가로 스크롤이 생긴다.
- Windows 에서 Python 한 줄 스크립트에 `C:\Users` 를 넣으면 유니코드 이스케이프 오류가 난다. 경로가 들어간 문서는 에디터 도구로 쓴다.

## 7. 검증 기준

- Playwright 로 데스크톱 1440, 모바일 375, reduced-motion 세 조건에서 연다. 콘솔 오류 0건, 404 0건, `scrollWidth > innerWidth` 거짓이어야 한다.
- 장면마다 스크린샷을 찍어 직접 본다. III 기준 27장이었다.
- reduced-motion 이면 Lenis 를 끄고 파티클은 최종 형태만, 영상은 포스터만 보여 준다.
- 검사 스크립트: `npm i` 후 `npm run check` (배포 주소) 또는 `node tools/check-pages.mjs http://127.0.0.1:4190/` (로컬). 새 페이지를 만들면 스크립트의 `PAGES` 에 추가한다. 2026-09-28 기준 5페이지 × 3조건 전부 통과.

## 8. 다음에 하면 좋은 것

- 장면 템플릿화: sticky + progress + onVisible 을 모듈로 빼면 새 장면을 빨리 붙일 수 있다. 지금은 III 파일 하나에 60KB 로 들어 있다.
- 영상을 스크롤 위치에 맞춰 되감는 스크럽 재생(`video.currentTime = p * duration`). 키프레임 간격을 짧게 다시 인코딩해야 부드럽다(`ffmpeg -g 1`).
- 소리. 아직 한 번도 안 넣었다.
