# MUSEUM 작업 노트

> 작성: 2026-09-28
> 결과물: `museum/index.html` (빌드 결과. 직접 고치지 않는다)
> 원본: `museum/index.src.html` (HTML, CSS) + `museum/src/*.js` (방별 스크립트) → `node museum/build.mjs`

## 방향

밤에 문 닫은 작은 현대미술관을 1인칭으로 걷는다. 스크롤이 곧 걸음이고, 카메라는 정해진 길을 따라가다 작품 앞에서 멈춰 돌아선다.
바닥은 반사되는 콘크리트, 방마다 벽색과 조명 분위기가 다르다. 크림, 아이보리, 베이지 벽은 쓰지 않았다.
서체는 로비 네온 글자에 Syne 700(구글 폰트, 캔버스에 그림), 나머지 한글은 Pretendard Variable.

## 방과 길이

`--len` 에 `:root --scroll-stretch`(1)를 곱한다. reduced-motion 은 정지 화면만 보여 주므로 0.4 로 줄인다.

## 기법과 수치 (전부 `src/00-core.js` 의 `CONFIG`)

**스크롤 → 길 좌표 u.** ScrollTrigger 없이 Lenis(lerp 0.08)만 쓴다. 방 섹션 6개의 offsetTop 과 높이로 u = 방 번호 + 방 안 진행률(0~6)을 직접 계산한다. 마지막 방은 높이에서 한 화면을 빼서 문서 끝에서 정확히 6이 된다.

**카메라 길.** `src/80-path.js` 에 키가 있다. 멈춤(hold)은 같은 자세의 키 두 개(속도 0)로, 지나가는 키는 Catmull-Rom 접선으로 만든 3차 에르미트 곡선이다. 그래서 작품 앞에서는 천천히 섰다가 떠나고, 문을 지날 때는 끊김 없이 걷는다. 시선은 주시점이 아니라 yaw, pitch 각도로 보간하고 yaw 는 짧은 쪽으로 돌도록 풀어 둔다. 포인터(데스크톱)나 자이로(폰)가 yaw 0.14, pitch 0.08 라디안까지 더한다.

**회화 배치.** 작품 높이만 정하고 폭은 텍스처의 실제 비율로 계산한다(프록시가 요청 크기를 무시하고 1374x1145, 1254 정사각 등으로 준다). 관람 위치는 벽에서 3.9m, 세로 화각 52도에서 작품이 화면 높이의 40~45% 를 차지한다. 스포트는 벽에서 2.3m, 천장 아래 0.2m, 세기 60, 각 0.5, 반영 0.6.

**반사 콘크리트.** 바닥은 캔버스로 만든 콘크리트 무늬 MeshStandard 이고, 그 위 4mm 에 `Reflector` 를 가산 합성으로 한 장 더 깐다. 반사 셰이더는 fbm 노이즈로 투영 좌표를 0.012 흔들고 세기 0.55 에 얼룩(0.75~1.25)을 곱한다. 어두운 바닥은 그대로, 밝은 것(네온, 스포트, 스크린, 레이저)만 비친다. 반사 타깃은 화면의 0.5배(모바일 0.35배).

**빛 원뿔.** 스포트마다 열린 ConeGeometry 를 램프 위치에서 조준 방향으로 세운다. 가산 합성, 램프에서 멀어질수록 `(1-t)^1.6`, 표면을 비스듬히 볼수록 `|dot(n, v)|^2.2` 로 흐려진다. 원뿔 길이는 조준점 거리의 0.94배다. 1.12배로 벽을 뚫게 두었더니 벽과 만나는 곳에 점선이 생겼다.

**조각.** 강철 띠는 BoxGeometry(0.62, 1.9, 0.12, 세분 220)를 높이에 따라 3.6라디안 비틀고 가늘게 한 것, 대리석은 IcosahedronGeometry(0.5, 40)을 mergeVertices 로 합친 뒤 사인 세 겹으로 부풀리고 허리를 조인 것(맥은 onBeforeCompile 에서 simplex 노이즈), 청동은 TorusKnot(2, 5). 금속 반사는 RoomEnvironment 를 어둡게 칠한 PMREM 을 조각 재질에만 준다(벽에 환경광을 주면 밤 분위기가 사라진다). 그림자는 조각 스포트 3개만, PCFSoft, 맵 1024(모바일 512).

**레이저 쌍곡면.** 천장 링(반지름 3.2, 높이 6.6)과 바닥 링 사이에 줄 40개. 아래 끝을 비틀림 각만큼 돌리면 허리가 잘록한 쌍곡면이 된다. 비틀림 = 1.9 + 방 진행률 × 1.1 + 속도 × 2.4, 속도 = `|lenis.velocity| × 0.012` 를 0.06 으로 따라감. 색은 코발트, 바이올렛, 마젠타, 라임을 줄마다 돌리고 속도로 색을 민다. 줄 굵기 0.03, 이득 2.2.

**영상실.** http 에서는 `<video>`(muted, loop, playsinline, preload none)를 VideoTexture 로 쓰고, 첫 `playing` 이벤트 뒤에 포스터에서 영상으로 바꾼다. u 3.55~5.25 에서만 재생한다. `file://` 에서는 영상 프레임이 캔버스를 오염시키므로 포스터(빌드 때 인라인)를 두고 `console.warn` 을 남긴다. reduced-motion 도 포스터만.

**후처리.** EffectComposer(HalfFloat, samples 4) + UnrealBloom(0.62, 0.55, 임계 0.86) + OutputPass(ACES). DPR 1.5 제한. 탭이 숨으면 그리지 않고 영상도 멈춘다.

**세로 화면.** 가로 화각이 64도 아래로 떨어지지 않게 세로 화각을 넓힌다(최대 92도).

## 함정 (전부 실제로 걸림)

- **블룸이 NaN 을 검은 사각 덩어리로 번지게 한다.** 화면 대부분이 까맣게 나왔다. 원인은 셰이더 두 곳이었다. 하늘의 `pow(dot(d, axis) * 3.2, 2.)`(음수 밑), 빛 원뿔의 `pow(0 에 가까운 값, y)`(ANGLE 은 pow 를 `exp2(y * log2(x))` 로 계산해 log2(0) 에서 NaN). 제곱은 곱셈으로 쓰고 pow 의 밑은 `max(x, 1e-4)` 로 막는다. 찾을 때는 `?debug` 로 장면을 열어 재질 종류별로 숨겨 가며 이분 탐색했다.
- **벽 두께를 잊으면 작품이 벽 속에 묻힌다.** 벽은 0.25m 상자라 안쪽 면은 경계 + 0.25 에 있다. 네온 글자와 스크린을 처음에 경계 + 0.15 에 두어 둘 다 안 보였다.
- **빛이 든 그룹을 숨기지 않는다.** `visible = false` 로 라이트 개수가 바뀌면 모든 재질이 다시 컴파일돼 걷다가 멈칫한다.
- **주시점 보간은 뒤집힌다.** 왼쪽 벽 작품에서 오른쪽 벽 작품으로 주시점을 옮기면 주시점이 카메라를 지나가는 순간 `lookAt` 이 천장을 본다. yaw, pitch 보간으로 바꿨다.
- 문 앞에서 시선이 문틀 쪽으로 돌면 화면이 벽 하나로 찬다. 문을 지나기 직전에 문을 정면으로 보는 키를 하나 더 둔다.
- 레이저 40줄이 겹치는 곳은 HDR 값이 매우 커져 블룸 밉 단계에서 네모난 빛 덩어리가 된다. 줄 이득 3.2 → 2.2, 바닥 점 3 → 1.4, 링 2.2 → 1.3 으로 낮췄다.
- 이미지 프록시가 `field`(색면 회화)에서 "no image" 빈 응답을 10번 연속 돌려줬다. 사각 색면 묘사를 두 번 바꿔도 안 되고, 수평선 세 줄 구성으로 주제를 바꾸자 됐다. 스크립트는 429 와 빈 응답을 모두 60초 뒤 재시도한다.
- Playwright 모바일 에뮬레이션(Chromium)은 `DeviceOrientationEvent.requestPermission` 을 노출해서 "기울기 켜기" 버튼이 스크린샷에 보인다. 실제 안드로이드에서는 안 보인다.

## 재료

`node tools/gen-images-museum.mjs [이름...]` (ChatGPT OAuth 프록시, 한 장씩, 429 나 빈 응답이면 60초 대기 후 최대 5회). PNG 를 250KB 이하 webp 로 바꾸고(품질 82 → 50 단계) PNG 는 지운다. 결과는 `assets/museum/`.
`build.mjs` 가 텍스처를 ffmpeg 로 긴 변 1024px, 품질 74 로 줄여 data URI 로 넣는다(HTML 약 755KB). 영상은 새로 만들지 않고 `assets/video/ad5-ink.mp4` 와 포스터를 썼다.

## 검증 (2026-09-28)

Playwright, 로컬 `python -m http.server 4224`. 1440x900, 375x812(모바일, 터치), reduced-motion, file:// 네 조건에서 콘솔 오류 0, 실패 요청 0, 가로 넘침 없음(조건마다 11지점). file:// 는 의도한 경고 한 줄만 남는다.
1280x720 에서 문서 전체를 휠로 조금씩 내리며 균등 40지점을 1.5초씩 기다려 찍었다. 한 색이 95% 넘는 거의 빈 화면 0장(가장 높은 단색 비율 0.65).
검사 중에만 쓰는 훅: 주소에 `?debug` 를 붙이면 `window.__museum` 에 THREE, world, walk 가 걸린다.
